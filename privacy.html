Política de privacidad

Última actualización: 21 de agosto de 2026

Resumen claro

La aplicación no utiliza servidores propios para recibir tus vídeos. La autorización y las operaciones de YouTube se realizan directamente entre tu dispositivo y los servicios de Google. La aplicación conserva localmente la autorización, preferencias e historial necesarios para funcionar.

2. Datos a los que accede la aplicación

  • Tokens OAuth de Google necesarios para mantener la autorización y renovarla.
  • Nombre e identificador del canal de YouTube autorizado.
  • Listas de reproducción y elementos de las listas del canal, incluidos títulos, identificadores, fechas y posiciones.
  • Vídeos que seleccionas, sus nombres, tamaños y metadatos necesarios para preparar el título y realizar la subida.
  • Preferencias de idioma, tema, formato de título, audiencia y selección.
  • Historial local de subidas terminadas, con el título, fecha y lista asociada, para informar al usuario y evitar duplicados accidentales.

3. Finalidades

La información se utiliza exclusivamente para autenticar al usuario, mostrar y administrar los canales y listas autorizados, subir los archivos seleccionados, crear u ordenar listas de reproducción, reanudar o cancelar tareas, presentar el progreso y conservar las preferencias e historial local de la aplicación.

4. Dónde se procesan y almacenan los datos

La aplicación no mantiene un servidor propio ni una base de datos remota de usuarios. Los vídeos y las solicitudes de administración se transmiten desde el dispositivo a las API de Google y YouTube. Los tokens, preferencias e historial indicados se guardan localmente en el almacenamiento privado de la aplicación, sujeto a las medidas de aislamiento y copia de seguridad del sistema Android.

La aplicación puede consultar un servicio DNS seguro de Cloudflare cuando necesita resolver servicios de Google en determinadas redes. Como ocurre con cualquier conexión de red, el proveedor puede recibir datos técnicos como la dirección IP, de acuerdo con su propia política.

5. Terceros

La aplicación se comunica con Google y YouTube para prestar sus funciones y, en el caso descrito, con Cloudflare para resolución DNS. El tratamiento realizado por esos proveedores se rige por sus propias condiciones y políticas. El desarrollador no vende datos personales ni comparte vídeos con redes publicitarias o intermediarios de datos.

  • Google Privacy Policy
  • YouTube Terms of Service
  • YouTube API Services Terms of Service
  • Cloudflare Privacy Policy

6. Base de uso y decisiones del usuario

El acceso a los datos de YouTube se produce después de que el usuario elige una cuenta, selecciona un canal y concede voluntariamente los permisos mostrados por Google. El usuario decide qué archivos seleccionar y cuándo iniciar, cancelar, ordenar o crear una lista.

7. Conservación y eliminación

Los datos locales permanecen mientras la aplicación está instalada o hasta que el usuario borra el historial, desconecta el canal, elimina los datos de la aplicación desde Android o desinstala la aplicación. Desconectar un canal revoca el permiso de Google y elimina los datos locales de autorización. El desarrollador no conserva copias remotas de los vídeos ni de ese historial.

8. Seguridad

Las comunicaciones con Google, YouTube y el servicio DNS indicado utilizan conexiones cifradas HTTPS. Los datos locales se guardan en el espacio privado asignado a la aplicación por Android. Ningún sistema es completamente infalible; recomendamos mantener Android y la aplicación actualizados y proteger el dispositivo mediante bloqueo de pantalla.

9. Menores

La aplicación no está dirigida a menores ni permite crear una cuenta propia del servicio. La opción de audiencia existe para que el usuario comunique a YouTube si cada subida contiene material creado para niños.

10. Cambios y contacto
